# Naukri Auto Apply Extension

A sophisticated, stealthy Chrome Extension that automates the job application process on Naukri.com. Built to save you time and maximize your job search efficiency while mimicking human behavior to avoid bot detection.

## 🚀 Features

- **Context-Aware Automation**: Automatically detects whether you are on a search results page or a job description page and acts accordingly.
- **Stealth Mechanics**: Uses randomized delays (waiting 3-7 seconds) and smooth scrolling to simulate actual human reading and interaction, significantly reducing the risk of being flagged by Naukri.
- **Smart Filtering**: Automatically skips "Apply on Company Site" jobs to keep your browser clean and focused on 1-click apply opportunities.
- **Premium User Interface**: Features a sleek, modern glassmorphism design with a live status dashboard and a daily application counter.
- **Automatic Tab Management**: Opens jobs in background tabs, clicks apply, and automatically closes the tab once the application is submitted.

## 🛠️ Installation

1. Clone or download this repository to your local machine.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** using the toggle switch in the top right corner.
4. Click on the **Load unpacked** button in the top left.
5. Select the folder containing this extension's code.
6. The Naukri Auto Apply extension should now appear in your list of extensions.

## 💻 Usage

1. Go to [Naukri.com](https://www.naukri.com/) and search for a job role (e.g., "Frontend Developer").
2. Click on the Naukri Auto Apply extension icon in your browser toolbar.
3. Click the **Start Bot** button.
4. The bot will begin scrolling through the job listings on the current page, opening them one by one, applying, and closing the tabs.
5. To pause or stop the automation at any time, click the **Stop** button in the extension popup.

## ⚠️ Important Notes

- **Keep the tab open**: Ensure the Naukri search tab remains open and active while the bot is running.
- **Rate Limiting**: To keep your Naukri account safe, it is highly recommended to limit your applications to around 50-100 per day. The bot tracks your daily application count in the popup dashboard.
